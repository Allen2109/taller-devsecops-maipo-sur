# Autoría y referencias

**Equipo que presenta esta adaptación:** Daniel Silva, Allen Ramirez y Antonella Mancilla.

**Fuentes de requisitos:** presentación «Taller DevSecOps sobre Infraestructura Crítica» y «Guía DevSecOps paso a paso v2», material del taller de la Universidad Bernardo O'Higgins, 2026.

**Referencia comparativa:** repositorio público **Taller-de-infraestructura-critica**, de Miguel Briceño (`miguelbriceno-sys`), URL: https://github.com/miguelbriceno-sys/Taller-de-infraestructura-critica. Su versión consultada fue una copia ZIP compartida con anterioridad. Se empleó como referencia para reconocer buenas prácticas de organización documental, automatización, diagramas, auditoría y trazabilidad.

**Diferenciación:** este proyecto mantiene una implementación didáctica propia del simulador Maipo Sur, con escenarios sectoriales, validaciones, diagrama y documentos redactados para esta entrega. No se atribuyen a nuestro equipo las ejecuciones, capturas ni resultados del repositorio de referencia.

**No verificado remotamente:** la URL pública y los resultados actuales de la cuenta de GitHub deben comprobarse desde GitHub. Cualquier prueba realizada por este equipo debe acreditarse con su enlace real.
